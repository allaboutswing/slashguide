# Slash Guide

Codex 슬래시 명령어를 배우는 한국어 정적 웹페이지입니다.

`index.html`을 브라우저로 열면 실행됩니다. 설치나 API 키가 필요하지 않습니다.

- 핵심 명령어 12개, 학습 단계 4개
- 앱 / IDE 확장 / 터미널 필터와 검색 (동시 적용)
- 명령어 복사, 사용 팁, 공식 문서 링크
- 브라우저에 저장되는 학습 완료 기록과 초기화
- 모바일 레이아웃, 키보드 탐색, 검색 단축키 `/`

자료 확인: 2026-09-10. 명령어 선정과 학습 순서는 이 가이드의 편집 기준이며 실제 사용 빈도 통계는 아닙니다.

공식 출처:
- https://learn.chatgpt.com/docs/reference/slash-commands
- https://learn.chatgpt.com/docs/developer-commands?surface=ide
- https://learn.chatgpt.com/docs/developer-commands?surface=cli

명령어 데이터와 지원 환경은 `app.js`, 레이아웃은 `index.html`, 스타일은 `styles.css`에서 수정합니다.
